## Hi, I'm Tamas 👋

I'm a software engineer who loves building small tools to make day-to-day work less stressful, simpler, and ultimately more enjoyable. I try to improve user experience, remove friction, and help people focus on what really matters.

Most of my projects start with the simple thought: **"There must be a better way to do this!"**

### Things I've built

* **[RetroBoard](https://retro.tamas.dev/)** - A real-time retro board I built because I wanted something focused and simple for my own team. It helps turn discussions into actions without the bloat and with some light touch.
* **[safari-cli](https://github.com/TamasNo1/safari-cli)** - Born from my vibe coding workflow. I needed an LLM agent to help debug a Safari-specific bug, but couldn't use MCP servers at work. So I built a CLI that gives the agent control over the browser.
* **[Certimon](https://certimon.com)** - Free SSL monitoring that runs entirely on Telegram.
* **[Accentless](https://accentless.app)** - A browser extension for instant accent correction in multilingual text.

More projects and write-ups at [thinkingbytes.co.uk](https://thinkingbytes.co.uk).
